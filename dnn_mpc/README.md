# 风险管控模块使用说明

包括控制模型训练、MPC 仿真、虚假数据注入（FDI）和重放攻击。四个页面使用纯 Python 算法；其他平台模块仍可能需要 MATLAB Runtime。

## 启动

```powershell
cd H:\repository\Platform_sjtu
conda activate project_sjtu
python Framework.py

# 或启动本机 Web；修改前端后添加 -Rebuild
.\start_web.ps1
```

Web 默认地址为 `http://127.0.0.1:8000`。新环境安装仓库根目录 `requirements.txt`；Web 构建依赖使用 `web_frontend/package.json` 和锁文件。已有 `project_sjtu` 环境无需重复安装。

## 使用流程

1. **控制模型训练评估**：指定 `.npz` 模型路径和输出目录，生成训练数据或选择已有 `.mat` 数据，设置样本数、轮数与网络参数后开始训练；结果区显示 RMSE 曲线。
2. **优化控制仿真验证**：使用最近训练的模型，或手动选择已有 `.npz` 文件，设置仿真时长与预测步长。通过“总览 / 状态响应 / 控制输入”切换图像。
3. **虚假数据注入**：设置 0.1～10 秒仿真时长，完成后查看“跟踪性能 / 扰动观测 / 状态与控制 / 增益与切换”四组图。
4. **重放攻击**：设置 0.1～50 秒仿真时长，完成后查看“跟踪性能 / 扰动观测 / 状态与控制 / 切换与重放”四组图。短仿真可能尚未进入攻击时段。

图像支持缩放和适配显示。桌面端通过导出按钮保存结果，Web 通过下载按钮获取结果。两端 FDI / 重放均可取消任务；取消后保留已显示的预览，不产生完整指标和结果导出。运行中的桌面任务结束或取消后再关闭窗口。Web 服务重启后需要重新运行任务。

四个模块均提供折叠式运行日志。训练 / MPC 两端采用左侧设置、右侧结果卡片布局，指标、说明和导出入口位于图像下方；窗口较小时可滚动查看。更新 Python 页面或 Web 后端后需重新启动对应程序，前端更新后需重新构建并刷新浏览器。

FDI / 重放在仿真过程中刷新四组曲线，可随时切换图像选项卡；刷新保留当前缩放和拖动位置。页面每 0.5 秒检查新图，实际更新间隔取决于计算和绘图速度。运行中的曲线只覆盖已经计算的时间段，仿真成功后显示完整 RMSE 并开放结果导出。

两端的 FDI / 重放 RMSE 均在左侧以“标签＋突出数值”显示，保留 4 位有效数字及尾零（例如 `0.02000`）。训练与 MPC 的指标保留在结果图下方：训练 RMSE 固定 6 位小数，MPC 跟踪 RMSE 固定 4 位小数。

MPC 当前使用预测网络推进闭环状态，属于模型内闭环验证；结果不能直接视为真实装置或独立被控对象验证。

## 输出与模型

默认输出相对于仓库根目录：

```text
dnn_mpc/python_output/
  training/runs/<运行ID>/
  mpc/runs/<运行ID>/
  fdi/runs/<运行ID>/
  replay/runs/<运行ID>/
  trained_model.npz
  latest_training_state.json
```

每次运行使用独立目录。训练、MPC 支持自定义输出路径；MPC 自动采用最近训练的模型，但保持自己的输出目录。模型、索引和既有历史结果无需移动。

FDI / 重放结果包含四组 SVG / PNG、`signals.npz`、`signals.csv` 和 `result.json`。训练 / MPC 的曲线、指标及导出包位于对应运行目录。运行数据由程序创建，不纳入 Git。
