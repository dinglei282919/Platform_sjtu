# 原模型到 Python 的对应关系

## 依据与边界

执行依据是上级目录 R2023a 版本 `switch_sim.mdl` 中 `/simulink/systems/system_root.xml` 的实际接线及相应 `.m` 文件，未用旧版 `.mdl.r2013b/.r2020b` 替代。旧版和论文仅保留为参考资料。

此实现迁移原代码的二阶切换观测器控制闭环，不是 MPC 优化器，也不是时滞论文的完整复现。现有 `plant.m` 没有延迟状态或历史缓存。没有加入反应热、温度或冷却水动力学，不能从框图外观推断模型包含这些变量。

`alfa3.m/beta3.m` 没有接入当前根系统，故不纳入状态。控制器中的 N3 来自 `ctrl.m`，不代表第三级 `alfa3.m` 已接入。

## 模型与控制律

模式 1：`w11=.75, w21=2, y11=.2, y21=.3`；模式 2：`w12=1, w22=1.8, y12=.4, y22=.3`。
两种模式共享 `r1=.3, r2=.2, g1=.4, g2=.5`。

```text
x₁' = x₂ − (1/w1 + decay1) x₁
x₂' = u − (1/w2 + decay2 − .2/.5) x₂ + 1.2 x₁
γ(t) = exp(t/(T−t+ℓ))                    t ≤ T
γ(t) = exp(T/ℓ)                          t > T
N(η) = exp(η²) cos(πη/2)
λ₁ = v₁ θ₁ᵀh₁ + 1.25 v₁³
λ₂ = v₂ θ₂ᵀh₂ + .5 v₂ + 1.5 v₂³
α₁ = −9v₁ + N(η₁)λ₁
α₂ = −(19+.5(kx₂)²)v₂ + N(η₂)λ₂
β₂' = γ(α₁−β₂)/.15
q' = γ v₂² α₂² − 30γq
η₃' = q v₂² α₂²
u = N(η₃)q v₂ α₂²
η₁' = v₁λ₁; η₂' = v₂λ₂
```

活动权重为 `θ' = −3γθ + γ v² h`。观测器使用真实原始 x₁ 的 h₁，以及估计状态 `(x̂₁,x̂₂)` 的 h₂，注入项分别为 `5γ(x₁−x̂₁)` 与 `8γ(x₁−x̂₁)`。

默认 `T=1.5, ℓ=.15`，后段 γ 为 exp(10)，与原代码一致。允许修改 T/ℓ 时，后段扩展为 exp(T/ℓ)以保持连续；这项参数化扩展不声称由原 MATLAB 代码验证。原代码把 exp(10)写死。支持时域止于 3 秒，避免把原 `signal.m/plant.m` 未定义区间自行延伸。

## MATLAB 索引语义

h₁ 的中心为 `[-15,-10,-5,0,5,10,15]`，宽度 b=5。

`alfa2.m` 和 `observer.m` 的 d2 为 2×7 矩阵，但循环调用的是 `d2(i)` 而非 `d2(:,i)`。MATLAB 按列展开，因此前七项为 `[-15,-15,-10,-10,-5,-5,0]`。Python 保留这个重复中心序列；每个标量同时减去二维输入的两个分量。没有未经用户确认改成常见的七个二维对角中心。

## 切换与数值处理

区间模式依次为：`[0,.2):2`, `[.2,.7):1`, `[.7,1.2):2`, `[1.2,1.6):1`, `[1.6,1.9):2`, `[1.9,2.3]:1`, `(2.3,3]:2`。2.8 秒处原代码前后均为 2，不是切换点。2.3 秒这个单点的输出模式按原 signal.m 显示为 1，其右侧积分采用模式 2。

积分在切换点和 T 处分段，避免跨越不连续点。输出网格额外包含所有分段边界。内部采用自适应步长，输出间隔不是积分步长。

高增益下优先采用刚性积分。Jacobian 使用复步长计算，避免在接近相等的信号相减时采用普通有限差分引入额外误差。2026-10-22 起将 37 列扰动合成一个批次求值，替代 37 次 Python 模型调用；单轨迹仍使用原来的标量收缩运算。该技术不改变控制律。没有限幅 u、截断指数或把 NaN 换成零；超范围会显式失败。

默认采用 BDF，rtol=1e-3、atol=1e-6。原 Simulink 配置是 VariableStepAuto，RelTol=1e-3、AbsTol=auto；Python 的绝对容差为显式工程选择，不能称为与 auto 完全相同。可在 JSON 配置中改用 Radau/BDF/LSODA 和更严格容差，但高增益会显著增加计算量。

当前指标 `peak_abs_u_sampled` 是输出采样网格中的峰值，不是连续时间的全局峰值。没有 MATLAB 工作区轨迹文件，现有 JPG/GIF 只能做外观参考，不能建立逐点数值误差。完成求解与数值复现是不同验证层级。
